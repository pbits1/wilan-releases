## 📦 Installation Guide

### Android
1. Download `WiLan-1.0.0-android.apk` on your device.
2. Open the downloaded file from your browser or file manager.
3. If prompted by Android, tap **Settings** and allow installation from this source.
4. Open **WiLan** and grant the required nearby device & storage permissions.

### Windows
1. Download `WiLan-1.0.0-windows.msi` (or `.exe`).
2. Double-click the installer and follow the quick setup wizard.
3. Launch **WiLan** from your Start Menu or desktop shortcut.

### Linux (Ubuntu / Debian / Linux Mint / Pop!_OS)
1. Download `WiLan-1.0.0-linux.deb`.
2. Open your terminal in the download folder and run:
   ```bash
   sudo apt install ./WiLan-1.0.0-linux.deb
   ```
   *(Or simply double-click the `.deb` file in your desktop file manager to install via Software Center).*
3. Launch **WiLan** from your application app launcher.

## ✨ Features

- **Fast Direct Transfer**: Optimized for local Wi-Fi networks with high-throughput streaming for instant, full-bandwidth file transfers.
- **100% Local & Private • Zero Cloud**: Files transfer directly between devices over your local Wi-Fi or personal hotspot. Your data never touches external servers or the cloud.
- **Smart Storage Protection**: Pre-checks available storage before receiving large files. If your drive is running low, switch destination storage with a single tap.
- **Automatic Organization**: Automatically sorts incoming files into dedicated folders (`Videos`, `Photos`, `Audio`, `Documents`, `Apps`, `Archives`).
- **Instant Web Sharing**: Share files seamlessly with iPhones, iPads, Macs, and Smart TVs through their web browser using a secure 4-digit PIN.
- **Device Security & Verification**: Direct device-to-device TLS encryption with cryptographic device fingerprint verification to ensure privacy.
